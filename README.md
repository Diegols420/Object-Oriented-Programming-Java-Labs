## 🚀 ¿Cómo ejecutar los proyectos?

### ✅ Requisitos previos
- [Java JDK 8+](https://www.oracle.com/java/technologies/downloads/)
- [NetBeans IDE](https://netbeans.apache.org/front/main/index.html)

### 📋 Pasos
1. Clona el repositorio:
```bash
git clone https://github.com/Diegols420/Object-Oriented-Programming-Java-Labs.git
```
2. Abre **NetBeans IDE**
3. Ve a `File → Open Project` y selecciona la carpeta del lab
4. Presiona `F6` para ejecutar
